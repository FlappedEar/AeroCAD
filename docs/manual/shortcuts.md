# Shortcuts

On a Mac, ++ctrl++ means ++cmd++ and ++alt++ means ++option++. In the program, **Help > Keyboard
Shortcuts** (++ctrl+slash++) shows the full searchable list. Single-letter keys do not fire while a
text field has focus: click in the 3D view first.

## General

| Key | Command |
|---|---|
| ++ctrl+n++ / ++ctrl+o++ / ++ctrl+s++ | New design / Open / Save |
| ++ctrl+z++ / ++ctrl+y++ (Mac: ++cmd+shift+z++) | Undo / Redo |
| ++f6++ | Fit all (frame the whole model) |
| ++v++ | Show / hide the selected part |
| ++delete++ | Delete the selected part |
| ++f2++ | Rename the selected part |
| ++m++ | Move / Rotate / Scale the selected part |
| ++a++ | Appearance (colour) of the selected part |
| ++s++ | Search commands and run one |
| ++ctrl+e++ / ++ctrl+shift+e++ | Export the selected part / all visible parts |
| ++esc++ | Cancel the current dialog or curve, go back to navigating, leave a sketch |

## Selecting an area of a scan

| Key | Tool |
|---|---|
| ++1++ | Region: click once, selects the smooth area around the click |
| ++2++ | Lasso: drag a loop around the area |
| ++3++ | Brush: paint (++bracket-left++ / ++bracket-right++ make it smaller / larger) |
| ++shift+up++ / ++shift+down++ | Grow / shrink the selection |

## Mouse and touchpad

| Action | Mouse | Touchpad / Magic Mouse |
|---|---|---|
| Orbit | Right drag, or ++shift++ + middle drag | ++shift++ + two-finger swipe |
| Pan | Middle drag, or ++shift++ + right drag | ++ctrl++ (⌘) + two-finger swipe |
| Zoom | Wheel (towards the pointer) | Two-finger swipe up/down, or pinch |
| Select | Left click | Click |
| Context menu | Right click without moving | Two-finger click |
| Zoom to a part | Double click on it | Double click on it |
| Fit all | Double click on empty space | Double click on empty space |

The left button only selects. If you have no middle button, click **Orbit**, **Pan** or **Zoom** in
the navigation bar at the bottom of the view: left drag then does that until you click the tool again.
