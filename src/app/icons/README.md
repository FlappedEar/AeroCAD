# Icons

24×24 monochrome SVGs, 1.6 px round strokes, black on transparent. They are tinted at run
time with the theme colours, see "Design system" in [docs/ui.md](../../../docs/ui.md).
Every `.svg` in this folder is compiled into the application (`qrc:/qt/qml/AeroCAD/icons/`).
